SecurityRegTest et SecTest : générateur de tests de régression de sécurité

Un outil qui détecte les vulnérabilités et génère automatiquement les tests qui empêchent une faille corrigée de réapparaître. Le projet existe en deux versions.

  • SecurityRegTest (Python, ligne de commande) : 10 catégories de vulnérabilités CWE, tests pytest générés et security gate GitHub Actions qui bloque le déploiement. Présenté dans un article scientifique.
  • SecTest (application web Spring Boot) : 46 règles CWE sur Java, Python et JavaScript, analyse d'APK Android avec apktool, tests JUnit générés, rapport PDF et explications par un LLM local (Ollama).

VPN site-à-site IPsec entre deux pare-feu de marques différentes

Interconnexion chiffrée de deux sites équipés de pare-feu différents, Sophos XG et OPNsense, pour valider leur interopérabilité. Le réseau est simulé dans GNS3, avec un routeur jouant le rôle d'Internet et un poste Kali sur chaque site pour les tests.

  • Tunnel IPsec IKEv2 : chiffrement ESP AES-256 / SHA-256, groupe Diffie-Hellman 14, authentification par clé pré-partagée.
  • Plan d'adressage sans chevauchement entre les deux LAN, trafic inter-sites sans NAT.
